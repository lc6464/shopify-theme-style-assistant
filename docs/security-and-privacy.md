# 安全与隐私

## 数据处理

样式提示助手会在浏览器本地读取当前选中分区或区块的 HTML、已渲染 CSS、尝试识别出的现有自定义 CSS，以及用户填写的修改需求。点击复制后，这些内容会进入用户剪贴板。

本项目不自动向 OpenAI、Claude、Shopify API、分析工具或任何外部服务发送提示词内容。用户需要自行判断要把提示词粘贴到哪里。

## 使用提醒

把提示词粘贴到第三方 AI 工具前，请先检查内容，避免发送：

- 顾客个人信息。
- 私密折扣或尚未公开的营销活动。
- 未公开新品或内部商业计划。
- 仅限公司内部使用的文案、图片或素材。
- 公司政策限制外发的任何内容。

## Shopify CSS 限制

Shopify 右侧自定义 CSS 输入框中尚未保存的更改无法被 Theme App Extension 自动读取。

助手会尝试从当前 HTML 结构末尾的 style 标签反向识别已保存自定义 CSS，但这个结果只能作为辅助。用户必须核对“现有自定义 CSS”输入框。如果输入框为空，助手会要求用户显式确认当前自定义 CSS 确实为空，因为错判可能导致后续全量替换时丢失原有样式。

## 运行边界

App embed 只在 Shopify 设计模式中加载。正常顾客访问店铺页面时不应加载助手资源。

## 分析统计

本项目不收集分析数据、遥测数据或使用事件。
